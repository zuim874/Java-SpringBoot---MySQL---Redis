但是绕过了400，注册遇到唯一主键数据库报错，返回500

========== 原因：
UserMapper 继承了 BaseMapper
MyBatis-Plus 的 selectOne 方法：MyBatis-Plus 的 selectOne 默认过滤逻辑删除数据，注册时需要用自定义 SQL 查全部
    // BaseMapper 的 selectOne
    default User selectOne(Wrapper<User> queryWrapper) {
        // 内部会执行：
        // SELECT * FROM sys_user WHERE username = 'admin' AND is_deleted = 0
    }

========== 解决方案：
1. 在 UserMapper 添加方法
import org.apache.ibatis.annotations.Param;
import org.apache.ibatis.annotations.Select;
@Mapper
public interface UserMapper extends BaseMapper<User> {

    // 查所有（包括已删除），用于注册时判断
    @Select("SELECT * FROM sys_user WHERE username = #{username}")
    User findByUsernameAll(@Param("username") String username);
}
2. 修改 UserService
public User findUsername(String username) {
    return userMapper.findByUsernameAll(username);  // 用自定义方法
}
