        键盘产生硬件中断（IRQ1），OS键盘驱动读取扫描码
        ```
        硬件中断：
            核心概念：
                · 中断请求（IQR[Interrupt Request]）：当硬件设备需要服务时，会向CPU发送一个电信号。每个中断源通常都有唯一的IRQ编号以便系统识别。

                · 中断控制器：协调 系统中的硬件设备的中断请求，如（PIC、APIC、GIC），负责决定哪个中断的优先级更高，然后传递给CPU。

                · 中断向量表：CPU收到中断后，需要知道去执行哪段代码来响应它。系统在启动时会建立一张中断向量表，存储了每个中断号对应的处理程序入口地址（这个地址指向操作系统的键盘驱动程序[内核态]）。
                    内核键盘驱动：读取键盘硬件寄存器，拿到扫描码，识别为回车键；将按键事件放到内核的 键盘输入缓冲区。

                    CPU的两种运行权限级别：
                        内核态：
                            · CPU拥有全部权限，可以访问全部硬件、全部内存、执行全部CPU命令。
                            · 可以：
                            操作硬件：网卡、键盘、磁盘、显卡；处理 IRQ 硬件中断；
                            管理内存：虚拟内存、页表、进程内存隔离；
                            进程调度：决定 CPU 接下来跑哪个进程 / 线程；
                            文件系统、网络协议栈 (TCP/IP)；
                            处理异常、缺页错误。
                        用户态：
                            · 权限被严格限制，普通应用程序（浏览器、IDEA、JVM、QQ）全部跑在用户态。
                            · 可以：读自己进程的内存、执行普通计算、跑 JS、跑 Java 业务代码
                        CPU特权环：
                            · Ring0 = 内核态，操作系统内核跑在这里
                            · Ring3 = 用户态，所有普通应用跑在这里
        ```
